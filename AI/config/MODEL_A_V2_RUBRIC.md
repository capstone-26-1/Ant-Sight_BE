# Model A v2 — 라벨 스키마 & 교사 프롬프트

> 교사: Qwen3-14B-Instruct (로컬, 4-bit) — 표본 라벨링
> 학생: KLUE-RoBERTa-base — 멀티태스크 파인튜닝 → production Model A v2
> 목적: 단순 감성지수 → 다성분 "개미지수"(한국 리테일 공포탐욕 지수)

---

## 1. Model A v2 per-post 출력 스키마

게시글 1건 → 아래 6개 필드:

| 필드 | 타입 | 값 | 설명 |
|---|---|---|---|
| `post_type` | 범주(5) | 분석정보 / 반응 / 조롱비난 / 질문 / 잡담홍보 | 글의 성격 |
| `stance` | 정수 −2~+2 | −2 강한약세 … 0 중립 … +2 강한강세 | 종목 방향성 견해 |
| `euphoria` | 정수 0~3 | 0 없음 … 3 극심 | 환희·탐욕·FOMO·과확신 |
| `anxiety` | 정수 0~3 | 0 없음 … 3 극심 | 불안·공포·우려 |
| `capitulation` | 정수 0~3 | 0 없음 … 3 극심 | 항복·절망·포기 |
| `anger` | 정수 0~3 | 0 없음 … 3 극심 | 분노·적대·비난 감정 |

학생 모델 = 1개 분류 헤드(post_type) + 5개 회귀/순서 헤드(stance, euphoria, anxiety, capitulation, anger).

---

## 2. post_type — 5분류 정의

| 코드 | 정의 | 예시 |
|---|---|---|
| **분석정보** | 근거·논리·사실·뉴스·수치·전망(이유 포함)을 담음 | "3분기 영업익 가이던스 상회, 환율 효과로 4분기도…" / "외인 5일째 순매수, 수급 돌아섬" |
| **반응** | 가격 움직임에 대한 감정적 반응, 근거 없음 | "또 떨어지네 ㅠㅠ" / "올랐다 좋다" / "오늘 왜 이래" |
| **조롱비난** | 다른 투자자·세력·경영진 조롱/비난/욕설 | "개미들 또 물렸네 ㅉㅉ" / "세력이 또 개미털기" / "경영진 사기꾼" |
| **질문** | 무언가를 물음 | "지금 사도 될까요?" / "배당 언제 들어오나요" |
| **잡담홍보** | 주제 무관 잡담·광고·리딩방 홍보 | "다들 식사하셨나요" / "텔레그램 무료 추천 ▶▶" |

판단 우선순위: 근거 있으면 분석정보 > 질문 > 조롱비난 > 반응 > 잡담홍보.

## 3. stance — 종목 방향성 견해 (−2~+2)

글쓴이가 *이 종목*을 어떻게 보는가. 감정이 아니라 **방향 견해**.

| 값 | 의미 | 단서 |
|---|---|---|
| +2 | 강한 강세 | "무조건 간다", 목표가 대폭상향, 풀매수 권유 |
| +1 | 약한 강세 | 긍정적이나 단정 아님 |
| 0 | 중립/불명 | 견해 없음, 질문, 잡담, 판단 유보 |
| −1 | 약한 약세 | 부정적이나 단정 아님 |
| −2 | 강한 약세 | "끝났다", 손절 권유, 폭락 단언 |

---

## 4. 감정 4차원 — 각 0~3 강도 (상호 배타 아님)

한 글이 여러 감정을 동시에 가질 수 있음 (예: 조롱글 = anger 3 + euphoria 1).

| 차원 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **euphoria** 환희·탐욕 | 없음 | 약한 낙관 | 뚜렷한 흥분("가즈아") | 광기("텐배거 확정 영끌") |
| **anxiety** 불안·공포 | 없음 | 가벼운 우려 | 뚜렷한 불안 | 공황("이러다 다 잃는다") |
| **capitulation** 항복·절망 | 없음 | 지침·회의 | 포기 직전("존버 한계") | 완전 항복("손절 끝, 떠난다") |
| **anger** 분노·적대 | 없음 | 짜증 | 뚜렷한 분노 | 격분·욕설 |

> anxiety vs capitulation: 불안=아직 기대 있음(예상). 항복=기대 버림(체념).

## 5. 합성 "개미지수" 산출 (0~100, 버킷 단위)

per-post 라벨 → (종목, 시간버킷) 집계 → 0~100 개미지수 (0 극공포, 100 극탐욕).
CNN 공포탐욕지수처럼 하위성분을 결합 (가중치는 차후 캘리브레이션):

```
greed_raw = mean(stance)/2 * 0.5 + mean(euphoria)/3 * 0.5
fear_raw  = mean(anxiety)/3 * 0.5 + mean(capitulation)/3 * 0.5
개미지수  = 50 + 50 * (greed_raw - fear_raw)        # 0~100 클램프
```
부가 출력: post_type 구성비(분석정보 비중 등), anger 평균, post_count, 여론분산.

## 6. 교사 프롬프트 (Qwen3-14B-Instruct)

라벨링 시 **non-thinking 모드 권장**(일관성·속도; `enable_thinking=False` 또는 `/no_think`).
few-shot 3~5개를 실제 종목토론방 글로 채울 것. JSON 한 줄만 출력하도록 강제.

```
[system]
너는 한국 주식 종목토론방 게시글을 분석하는 라벨러다. 게시글 하나를 읽고
아래 스키마대로 JSON 한 줄만 출력한다. 설명·사족 금지.

post_type: "분석정보"|"반응"|"조롱비난"|"질문"|"잡담홍보"
stance: -2~2 정수 (종목 방향성 견해)
euphoria/anxiety/capitulation/anger: 0~3 정수 (감정 강도)

[정의]
(위 2·3·4절 정의를 여기 붙여넣기)

[예시]
입력: "3분기 영업익 컨센 상회했고 환율도 우호적. 4분기 더 좋을 듯"
출력: {"post_type":"분석정보","stance":1,"euphoria":1,"anxiety":0,"capitulation":0,"anger":0}

입력: "개미들 또 물렸네 ㅉㅉ 세력 설거지 시작"
출력: {"post_type":"조롱비난","stance":-1,"euphoria":0,"anxiety":0,"capitulation":0,"anger":3}

입력: "손절했습니다 더는 못 버팁니다 다들 안녕히"
출력: {"post_type":"반응","stance":-2,"euphoria":0,"anxiety":1,"capitulation":3,"anger":0}

[입력]
{게시글 제목 + 본문}
[출력]
```

## 7. 파이프라인 로드맵

1. **루브릭 확정** ← 현재 단계 (이 문서 검토)
2. **라벨링 표본 설계** — 종목·기간 층화 + post_type 커버리지 확보, 약 2~3만 글
3. **라벨링 스크립트** — Qwen3-14B(vLLM/Ollama)로 표본 라벨 생성 → 사용자 PC 실행
4. **라벨 품질 점검** — 소표본 수동 검수, 분포 확인
5. **학생 학습 스크립트** — KLUE-RoBERTa 멀티태스크 파인튜닝
6. **전량 추론** — 학생 모델로 170만 글 → 6개 필드
7. **개미지수 집계** — 5절 산출식 → 신규 테이블
8. **검증** — (a) 상태지수: 동시기 타당성 (b) 예측: 분석정보글만 stance로 forward IC (8번째·마지막 예측 테스트)
